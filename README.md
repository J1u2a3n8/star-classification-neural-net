## Description

Machine learning project classifying stellar spectra using deep neural networks. Implements data preprocessing, feature engineering, model training with TensorFlow/Keras, hyperparameter tuning, and model evaluation with confusion matrices and ROC curves.

## Architecture

ML Pipeline: Data Ingestion → Preprocessing → Feature Engineering → Model Training → Evaluation → Inference API

## Quick Start

### Prerequisites

.NET 8 SDK, Visual Studio 2022 / VS Code with C# Dev Kit

### Installation

```bash
# Clone
git clone https://github.com/J1u2a3n8/star-classification-neural-net.git
cd star-classification-neural-net

pip install -r requirements.txt
# jupyter lab
```

### Usage

```bash
jupyter notebook notebooks/star-classification.ipynb
```

## Testing

```bash
pytest tests/
```
